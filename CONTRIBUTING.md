# Contributing

- One issue, one branch, one focused change.
- Branch naming: `feat/`, `fix/`, `test/`, `docs/`, `chore/`.
- Conventional commits: `feat(tracking): add deterministic frame alignment`.
- Run `pytest -q`, `ruff check .`, and `ruff format --check .`.
- Never commit credentials, proprietary data, raw recordings, or model weights.
- Hardware actions require supervised, explicitly authorized execution and a physical stop procedure.
